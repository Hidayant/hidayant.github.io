Cara Reset Waste Ink Pad Counter Epson L360 (Adjprog)

Printer Epson Repair
  • 1 Buka Aplikasi: Ekstrak file zip yang sudah diunduh, lalu jalankan program Adjprog.exe.
  • 2 Pilih Printer: Klik tombol Select. Pada kolom Model Name, pilih L360. Biarkan Port pada posisi default (Auto selection), lalu klik OK.
  • 3 Masuk Menu Perbaikan: Klik tombol Particular adjustment mode. Pada daftar menu yang muncul, pilih opsi Waste ink pad counter, lalu klik OK.
  • 4 Cek & Reset Counter: Beri centang pada kotak Main pad counter, lalu klik tombol Check (jika 100%, kuota bantalan limbah penuh). Centang kembali kotak Main pad counter, kemudian klik tombol Initialize. Klik OK pada konfirmasi popup dan tunggu proses penulisan ulang selesai.
  • 5 Restart Printer: Saat muncul jendela perintah mematikan printer, matikan printer melalui tombol power fisiknya, lalu klik OK pada komputer. Nyalakan kembali printer Anda, lalu klik OK pada notifikasi terakhir.
  • 6 Selesai: Penghitung (*counter*) berhasil kembali ke 0% dan lampu indikator error printer akan normal kembali.

Konfigurasi Dasar Mikrotik dari Nol Sampai Online

Mikrotik Router Setup
  • 1 Koneksi Fisik & Login Winbox: Hubungkan kabel modem ke ether1 dan PC ke ether2. Login via Winbox menggunakan MAC Address, user admin tanpa password. 02:50
  • 2 Identitas & Penamaan: Ganti nama router di System > Identity. Beri nama interface pada menu Interfaces (misal: ether1-Internet, ether2-LAN). 05:49
  • 3 Konfigurasi DNS: Buka IP > DNS, isi Server DNS: 8.8.8.8 dan 8.8.4.4. 07:56
  • 4 Terima IP ISP (DHCP Client): Buka IP > DHCP Client, buat client baru pada ether1-Internet. Uji koneksi via terminal: ping google.com. 08:38
  • 5 Firewall NAT: Masuk IP > Firewall > NAT. Buat rule baru: Chain srcnat, Out Interface ether1-Internet, Action pilih masquerade. 09:44
  • 6 Tetapkan IP Segmen Lokal: Masuk IP > Addresses, beri IP lokal (misal ether2-LAN: 10.10.10.1/24). 11:10
  • 7 DHCP Server Client: Buka IP > DHCP Server, klik tombol DHCP Setup pada interface lokal hingga selesai. 13:13
  • 8 Amankan Akun: Masuk ke System > Users, ganti password default admin. 15:24

Konfigurasi File Sharing & Permissions (Active Directory)

Win-Server Storage Security
  • 1 Struktur Folder: Siapkan folder utama (misal: C:\Share) beserta subfolder divisinya (seperti General, Sales, Legal). 02:30
  • 2 Folder Publik (Read-Only): Klik kanan folder > Properties > Sharing > Advanced Sharing > centang Share this folder. Di Permissions, biarkan grup Everyone dengan hak Read saja. 03:55
  • 3 Folder Divisi Tertutup (Restricted): Pada Advanced Sharing > Permissions, Remove grup Everyone. Klik Add grup AD (misal: Sales) dan centang Full Control. 08:12
  • 4 Sinkronkan Hak Akses NTFS: Buka tab Security folder > klik Edit > Add grup divisi yang sama > centang Full Control (Wajib disamakan agar izin tidak bentrok). 08:59
  • 5 Uji Akses Klien: Dari PC klien tekan Win + R, ketik format UNC Path: \\Nama-Server atau \\IP-Server. 05:50
  • 6 Manajemen Share Terpusat: Buka Computer Management > Shared Folders > Shares untuk melihat daftar folder sharing, mengubah izin, atau menghentikan share. 16:58
